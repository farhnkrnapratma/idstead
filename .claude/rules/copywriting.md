# Copywriting

All UI microcopy, command descriptions, placeholders, tooltips, error messages and documentation are concise, precise, professional American English (en-US), even when the conversation is in another language.

- State actions directly, in single sentences or fragments, without filler or exaggeration.
- Prefer plain words over implementation names (`sans`, `serif`, `mono`, not font package names).
- Keep the tone neutral and informative.
