The current mark is the wordmark only: the word `Idstead` set in the site's monospace font at semibold weight, as in the site navigation and footer.

## Adding assets

Add a file here only once its design is final. Use these names:

| File           | Content                                          |
| -------------- | ------------------------------------------------ |
| `wordmark.svg` | The wordmark with its text converted to outlines |
| `logo.svg`     | The logo mark, when there is one                 |
| `logo-512.png` | A 512 × 512 raster of the logo                   |
