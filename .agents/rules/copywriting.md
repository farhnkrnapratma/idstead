## Copywriting & In-App Text

All UI microcopy, command descriptions, search guides, placeholders, tooltips, and documentation must adhere strictly to concise, precise, and professional en-US copywriting.

Rules:

- **Concise & Precise**: Eliminate verbose, exaggerated, or redundant text. State actions directly in single sentences or fragments without fluff.
- **KISS (Keep It Simple)**: Avoid unnecessary technical jargon or raw implementation names where simple terms suffice (e.g. use `sans`, `serif`, `mono`).
- **Professional Tone**: Keep phrasing neutral, informative, and direct.
- **Strict en-US Language**: 100% of UI copy, error messages, and documentation must use American English (en-US).
